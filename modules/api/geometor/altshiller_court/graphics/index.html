geometor.altshiller_court.graphics¶

Bounding-box figure cropper and dark-mode inverter for College Geometry folios.

Compatible natively with publish folio (photon_platform.publish.folio_review), reading <NNNN>.json definitions of the form:

{
          "folio": "0023",
          "page": "4",
          "graphics": [
            {
              "id": "g1",
              "type": "diagram",
              "file": "0023.g1.png",
              "bbox": [x, y, w, h],
              "caption": "Fig. 1 — Construction of a circle touching a line at a given point and passing through an external point.",
              "white_point": 238
            }
          ]
        }

Generates both <NNNN>.<gid>.png (clean white-point normalized light-mode diagram) and <NNNN>.<gid>.inverted.png (crisp dark-mode diagram).
