geometor.altshiller_court.compile_edition¶

Book Codex compiler and scholarly apparatus builder for College Geometry (1952).

Compiles verified diplomatic folio transcriptions (resources/college_geometry/<dir>/<NNNN>.rst and <NNNN>.notes.rst), diagram crops (<NNNN>.g<k>.png), interactive SVGs (<NNNN>.g<k>.svg), structure_map.json, and apparatus registries (persons.json, citations.json, glossary.json, folio_reviews.json) into a multi-level Euclid-style Book Codex (Book -> Chapters -> Sections -> Items) with .. collection:: navigation and Commentary companion tracks under docsrc/college_geometry/.
