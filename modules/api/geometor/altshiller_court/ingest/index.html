geometor.altshiller_court.ingest.ingest_folios(repo_root: pathlib.Path, dpi: int = 300, force: bool = False) → dict[str, Any]¶

Render all 334 PDF pages at dpi and route into chapter directories.

Cover folios (0001 and 0334) preserve full RGB color; interior text and diagram folios (0002–0333) are saved as crisp 8-bit grayscale PNGs with zero loss of line stroke or anti-aliasing fidelity.
