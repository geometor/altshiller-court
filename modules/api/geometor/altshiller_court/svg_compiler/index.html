geometor.altshiller_court.svg_compiler¶

Semantic Ink-to-Vector SVG compiler and overlap verifier for Altshiller-Court’s College Geometry.

Compiles formal "geometry" models stored in <folio>.json into interactive euclid-graphic SVGs compatible with photon_platform.publish (geometor_interactive.js), and quantitatively verifies sub-pixel alignment against the 300-DPI <folio>.<gid>.png crops.

geometor.altshiller_court.svg_compiler.canonical_point_ref(pt_key: str) → str¶

Return collision-safe point data-ref compatible with geometor_interactive.js.

In geometor_interactive.js, bare point references strip non-alphanumeric characters (str.replace(/[^A-Za-z0-9]/g, '')). Mapping primed points A' -> Aprime and P_1' -> P1prime prevents A' from colliding with unprimed A, while P_1 naturally normalizes to P1.

Rasterize visible geometric primitives and measure pixel overlap against <folio>.<gid>.png.

Computes:

  • overlap_score: percentage of rasterized SVG stroke pixels falling within tolerance_px of actual scan ink pixels (target >= 95.0%).

  • scan_recall: percentage of non-label scan ink pixels covered within tolerance_px by the rasterized SVG strokes.
