.. assertion:: [Discussion]

   The problem is impossible, unless :math:`a > (b - c)`. When this condition is satisfied, the :g:`given angle <0043.g1:< B D C )>` in the triangle :g:`BCD <0043.g1:< B C D >>` lies opposite the larger side :g:`BC <0043.g1:/ B C />`, and this triangle may be constructed in one way only. The proposed problem has thus one solution.

*Note.* The angle :g:`BCD <0043.g1:< B C D )>` of the auxiliary triangle :g:`BCD <0043.g1:< B C D >>` is equal to the angle :g:`C <0043.g1:< C )>` of the triangle :g:`ABC <0043.g1:< A B C >>`, angle :g:`BDC <0043.g1:< B D C )>` :math:`= 90^\circ + \tfrac{1}{2}\,A`, and:

.. math::

   \begin{aligned}
   \angle CBD &= \angle ABC - \angle ABD = B - (90^\circ - \tfrac{1}{2}\,A) \\
              &= B + \tfrac{1}{2}\,A + \tfrac{1}{2}\,C - \tfrac{1}{2}\,C - 90^\circ \\
              &= \tfrac{1}{2}(A + B + C) + \tfrac{1}{2}(B - C) - 90^\circ = \tfrac{1}{2}(B - C).
   \end{aligned}

EXERCISES
~~~~~~~~~

Construct a triangle, given:

1. :math:`b - c, a, C`.
2. :math:`b - c, a, B - C`.
3. :math:`b - c, h_b, C`.
4. :math:`b - c, h_b, B - C`.
5. :math:`b - c, A, B`.
6. :math:`b - c, h_b, A`.

.. enunciation::

   **19. Problem.** *Construct a* :g:`triangle <0044.g1:< A B C >>` *given the* :g:`base <0044.g1:/ B C />`\ *, the* :g:`difference of the other two sides <0044.g1:/ B E />`\ *, and the* :g:`altitude <0044.g1:/ C K />` *to one of these sides* :math:`(a, b - c, h_c)`.

Let :g:`ABC <0044.g1:< A B C >>` (Fig. 20) be the required triangle. Produce :g:`AB <0044.g1:[ B A ]>` and lay off :eq:`AE = AC <0044.g1:/ A E / = 0044.g1:/ A C />`, so that :g:`BE <0044.g1:/ B E />` :math:`= b - c`. In the triangle :g:`BCE <0044.g1:< B C E >>` we have :g:`BC <0044.g1:/ B C />` :math:`= a`, :g:`BE <0044.g1:/ B E />` :math:`= b - c`, and the :g:`altitude <0044.g1:/ C K />` to :g:`BE <0044.g1:[ B A ]>` equal to :math:`h_c`; hence this triangle may be constructed, and from this triangle we readily pass to the required triangle :g:`ABC <0044.g1:< A B C >>`.
