§ 17. Exercises (1–9)
=====================

.. folio:: 0042
   :page: 23

Construct a triangle, given:

1. :math:`b + c, a, B` (or :math:`C`).
2. :math:`b + c, B, h_c`.
3. :math:`b + c, C, a`.
4. :math:`b + c, A, B`.
5. :math:`b + c, a, h_b` (or :math:`h_c`).
6. :math:`b + c, a, B - C`.
7. :math:`b + c, h_c, B - C`.
8. :math:`b + c, h_b, B - C`.
9. :math:`b, c, B - C`. *Hint.* Construct :math:`b + c`. In the triangle :math:`BCD` we have the vertices :math:`B, D`, and a :term:`locus <geometric-locus>` for :math:`C`. Lay off :math:`BA = c`. The point :math:`C` lies also on the circle :math:`(A, b)`.
