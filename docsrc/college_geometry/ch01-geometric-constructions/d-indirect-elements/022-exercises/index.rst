§ 22. Exercises (1–4)
=====================

.. folio:: 0047
   :page: 28

Construct a triangle, given:

1. :math:`h_c - h_b, B, C`.
2. :math:`h_c - h_b, b, c`.
3. :math:`h_c - h_b, b - c, B - C`.
4. :math:`h_c - h_b, A, b + c`.
