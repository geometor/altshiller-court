§ 21. Exercises (1–6)
=====================

.. folio:: 0046
   :page: 27

Construct a triangle, given:

1. :math:`h_b + h_c, B, C`.
2. :math:`h_b + h_c, b, c`.
3. :math:`h_b + h_c, b, A`.
4. :math:`h_b + h_c, b + c, a`.
5. :math:`h_b + h_c, b + c, B - C`. *Hint.* The triangle :math:`BGH` determines :math:`A`, and :math:`B + C = 180^\circ - A` is thus known, hence the angles :math:`B` and :math:`C` may be constructed.
6. :math:`h_b + h_c, b - c, A`.
